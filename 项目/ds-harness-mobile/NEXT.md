## 已知坑

- **「暂无会话」≠ 会话丢了**：真实含义是没连上（数据没拿到）。判据是看「工作区」下面有没有工作区名
  ——一个名字都没有就是没拿到数据。0.3.2 起 App 会在那行字下面挂一张人话说明卡。
- **这条链对浏览器/WebView 有依赖**：实测某浏览器上 `/api` 全通（200）却完不成 WebSocket 的
  generation 握手（客户端 3s 警告 / 15s 报错 → 退避重连），**换个浏览器立刻正常**。
  排查手机问题时**先换浏览器**排除这一层。
- **中继现在活在桌面端进程里**（桌面端 0.3.8 起）：桌面端**退出**才断（点 ✕ 只是缩到托盘，仍连着）；
  重开即恢复、**不用重扫**。若同时还开着 `启动手机访问.cmd` 的独立中继，两边会抢 8787
  （会自动顺延到 8788），建议只留一个。
- **地址变化要重扫**：官方 cookie 与访问时的 authority 绑定 → **域名 ↔ IP、或端口变化**后，
  手机上必须重新扫一次二维码；只重启桌面端不会。
- **桌面端跑的 dsh ≠ 它自带的那个**：实际用的是自更新下来的
  `%APPDATA%\ds-harness-desktop\dsh-update\versions\<版本>\`。读源码/下结论前先看日志里的 bin 路径。
- **不要批量杀 node 进程**：会把 harness 自己的后台任务管理器一起带走。只按 PID 精确清理。
- **`v2/` 缺 `local.properties` 直接 BUILD FAILED**（报错只说 "SDK location not found"）；
  本机 `ANDROID_HOME` 是空的，必须靠这个文件。构建脚本读的 keystore 是 **`v2\release.keystore`**
  （仓库根那把是 v1 的、同一把密钥；新机器要么拷一份进 `v2\`，要么自带）。
- **缺 `release.keystore` 时构建是"绿"的**，只静默产出未签名包 → 装到手机才因签名不符失败。
- **资源别写错模块**：仓库根有 v1 的 `app/`，v2 的在 `v2/app/`；v1 工程按约定一行不动。
- **XML 注释里不能出现连续两个连字符**（写 `--host` 这类字面量会让资源编译失败）。
- **改窄屏布局的两条硬约束**：① 开合状态跟着官方 `data-sidebar-collapsed` 走，开合一律"点官方按钮"；
  ② 侧栏一旦 `position: fixed`，三列必须显式钉 `grid-column: 1/2/3`（只改 `grid-template-columns`
  会导致主区宽 0）。选择器只用 `[class*="_后缀"]` 这类稳定钩子，**不写哈希前缀**。
- **不要把 bind 改成 `0.0.0.0`**：官方 CLI 明确拒绝，绕过去属于绕过厂商安全闸，本项目不采用；
  中继只绑尾网地址。
- **明文 HTTP 是整体放行的**（`network_security_config.xml` 有解释）：电脑地址运行时输入、形态不一，
  编译期无法用 `<domain>` 精确枚举；风险由"只连自己的地址 + Tailscale"兜底。
- **工作区路径含空格** → `v2/gradle.properties` 开着 `android.overridePathCheck=true`，
  构建时打一行 experimental 警告属正常。
- **本机（A机）工具链两坑（2026-09-25 新增）**：
  ① PowerShell 5.1 的 `Get-Content -Raw` 按 GBK 读 UTF-8 脚本，中文被撕碎时可能吞掉一个 ASCII
  字符（引号）→ 注入的 JS 报语法错；读文件用 `[System.IO.File]::ReadAllText(p, UTF8Encoding($false))`。
  ② 写 `.bat`/`.ps1` 时中文会变成 `??`，别用 ASCII 编码写含中文的脚本。
- **判断"元素可见"别用内联样式**：要用 `getClientRects().length > 0 && offsetWidth > 0`；
  本轮曾因"内联样式不是 none"放过一个真 bug（二维码白框不显示）。
