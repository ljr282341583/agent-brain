# CONTEXT — protocol-generator(人民调解协议生成器)

> 新会话 / 另一台机器开工前必读。项目定位或阶段大变时更新本文件。

## 项目是什么

面向基层人民调解员的**纯前端单文件 HTML 应用**:引导式录入纠纷信息,自动生成符合《人民调解法》(第 28-33 条)与司法部文书格式的人民调解协议书,并可一键生成全套卷宗文书(12 种)+ 个人卷宗文书(8 种)+ 治安文书,支持 Word(.doc/.docx)导出、打印、HTML 预览、模板导入导出、案件草稿自动保存。零依赖、零安装,数据全程留在浏览器本地。

## 怎么跑

- **没有构建步骤**:直接用浏览器打开对应 HTML 即可。改代码 = 改 HTML 里的内联 JS/CSS,保存即生效。
- 方案二需先按 `方案二授权码/设备绑定/Supabase配置指南.html` 配好 Supabase(表 `device_bindings`,匿名登录);另有 CloudBase 备选指南。
- 发布流程(现状):每版另存新文件名(如 `…启动码v5.9.1.html`)→ 同步 README 更新日志 → 旧版移入 `历史版本/` 或并存保留。

## 技术要点(改动前必知)

- 单文件 HTML + Tailwind CDN + 原生 JS,一个文件含全部逻辑(最新版 300KB+)。
- docx 导出为自研实现:原版 docx 模板 base64 内嵌 → 解 zip → 替换 `word/document.xml` 字段 → 重新打包;纯文本类则现场生成最小 OOXML 包。
- **老内核兼容**:Chromium 80~102 有 DecompressionStream 但不支持 `deflate-raw`,导出链路靠页面内 `dsh-compat` 代码块(纯 JS puff 算法)兜底——动导出代码时不能删这块(v5.5.1 的教训)。
- 无正式测试框架;历史上用「Node + vm 提取页面真实函数」做端到端验证,脚本散落在 A 机 DSH 工作区根目录(`verify-dsh-export.js`、`_test_certtype.js`、`_test_attendees.js`),**不在仓库里**(详见 NEXT 已知坑)。
